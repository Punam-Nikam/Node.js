# 🚀 Node.js Learning Repo

Welcome to my **Node.js Learning Repository**!

This repository contains the programs and examples that I wrote while learning Node.js from scratch. The purpose of this repository is to understand Node.js fundamentals, core modules, asynchronous programming, file handling, HTTP servers, and other basic concepts through hands-on practice.

---

## 📚 Topics Covered

- Node.js Basics
- Core Modules
  - File System (fs)
  - Path (path)
  - Operating System (os)
  - HTTP (http)
- File Handling
- Copying Files
- Custom Functions & Modules
- Event Emitter
- HTTP Server
- Express.js Basics
- JavaScript Objects
- Arrays
- TypeScript Basics
- Interfaces in TypeScript

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Navigate to the project folder

```bash
cd NodeJS-Learning
```

### 3. Run any JavaScript file

Example:

```bash
node basics.js
```

or

```bash
node app.js
```

or

```bash
node Server.js
```
