# 🚀 My Node.js & React Learning Journey

Welcome to my learning repository! This repo is a collection of all the concepts, practice projects, and code snippets I am building while learning backend development with **Node.js** and frontend development with **React**.

## 📚 What I Am Learning
I am actively exploring and practicing the following concepts:
- **Node.js Core:** File System, Event Emitters, Async/Await, Promises, Callbacks.
- **Express.js:** Routing, Middleware, RESTful APIs, Error Handling.
- **MongoDB:** Database connections, Mongoose, and Centralized Middleware.
- **Authentication:** Passport.js (Local Strategy & JWT Strategy).
- **CORS:** Handling Cross-Origin Resource Sharing (With and Without CORS).
- **React:** Components, Props, State, and React Hooks.

## 📂 Repository Structure

Here is a quick overview of what you will find in this repository:

*   **`Corsss/`** - Practice code for Cross-Origin Resource Sharing (with and without CORS).
*   **`ExpressJs/`** - Core Express concepts including Middleware, HTTP Requests, and RESTful API setups.
*   **`MongoExpress/`** - Integrating MongoDB with Express, including Centralized Middleware and student data handling.
*   **`Passport strategy/` & `PassportJS/`** - Learning authentication using Passport.js, including JWT and Local strategies.
*   **`ReactDemo/`, `myapp/`, & `studentRef/`** - React projects built with Vite. Includes practice with components (`App1.jsx` to `App5.jsx`), state, and hooks.
*   **`js/`, `newFolder/`, `QueOne/`, `QueTwo/`** - Core Node.js module practice, exercises, and other general scripts.

## 🛠️ Technologies & Tools Used
*   **Backend:** Node.js, Express.js
*   **Database:** MongoDB, Mongoose
*   **Frontend:** React (Vite, JSX, Hooks, State)
*   **Authentication:** Passport.js (JWT, Local Strategy)
*   **Other Tools:** Postman, Git, VS Code
